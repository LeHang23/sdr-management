# RS-01 - Điều hướng chung

| Trường | Giá trị |
| --- | --- |
| Màn hình | Admin Dashboard |
| FBS | FBS-1.0.1, Global navigation |
| Ưu tiên | Must |

## Mục tiêu

Cho phép Administrator di chuyển giữa các module và hiểu vị trí hiện tại.

## Yêu cầu

| ID | Yêu cầu |
| --- | --- |
| RS-DASH-NAV-01 | Điều hướng phải gồm Overview, Devices, Reconfiguration, Monitoring, Firmware, Config profiles, Alerts và Audit log. |
| RS-DASH-NAV-02 | Điểm đến đang hoạt động phải dễ nhận biết bằng hình ảnh và programmatically. |
| RS-DASH-NAV-03 | Chọn điểm đến đã khả dụng phải mở đúng màn hình tương ứng. |
| RS-DASH-NAV-04 | Điểm đến chưa triển khai không được dẫn đến trang lỗi. |

## Tiêu chí chấp nhận

- Overview ở trạng thái active trên Admin Dashboard.
- Người dùng bàn phím và con trỏ truy cập được mọi điểm đến khả dụng.
