# RS-02 - Hiệu năng hệ thống

| Trường | Giá trị |
| --- | --- |
| Màn hình | Overview |
| FBS | FBS-1.1.2, System performance |
| Ưu tiên | Must |

## Mục tiêu

Cho phép Administrator theo dõi xu hướng Throughput và SNR tổng hợp.

## Yêu cầu

| ID | Yêu cầu |
| --- | --- |
| RS-OVW-PERF-01 | Panel phải vẽ Throughput theo Mbps và SNR theo dB qua thời gian. |
| RS-OVW-PERF-02 | Chart phải phân biệt rõ hai metric và đơn vị. |
| RS-OVW-PERF-03 | Administrator phải chọn được khoảng thời gian được hỗ trợ. |
| RS-OVW-PERF-04 | Loading, empty, partial-data và error state phải hiển thị rõ. |

## Tiêu chí chấp nhận

- Hai metric mô phỏng render đúng label và đơn vị.
- Đổi time range chỉ refresh dữ liệu cần thiết.
