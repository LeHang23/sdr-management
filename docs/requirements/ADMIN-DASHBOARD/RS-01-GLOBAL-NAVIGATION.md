# RS-01 - Global Navigation

| Field    | Value                      |
| -------- | -------------------------- |
| Screen   | Admin Dashboard            |
| FBS      | FBS-1.0.1, Global navigation |
| Priority | Must                       |

## Goal

Allow an Administrator to move between product modules and understand the
current location.

## Requirements

| ID | Requirement |
| --- | --- |
| RS-DASH-NAV-01 | Navigation shall include Overview, Devices, Reconfiguration, Monitoring, Firmware, Config profiles, Alerts, and Audit log. |
| RS-DASH-NAV-02 | The active destination shall be visually distinguishable and programmatically identifiable. |
| RS-DASH-NAV-03 | Selecting an enabled destination shall open its corresponding screen. |
| RS-DASH-NAV-04 | Destinations not yet implemented shall not lead to a broken page. |

## Acceptance criteria

- Overview is active on the Admin Dashboard.
- Keyboard and pointer users can reach every enabled destination.
