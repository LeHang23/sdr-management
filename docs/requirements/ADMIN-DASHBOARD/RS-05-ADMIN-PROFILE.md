# RS-05 - Admin Profile

| Field | Value |
| --- | --- |
| Screen | Admin Dashboard |
| FBS | FBS-1.0.5, Admin profile |
| Priority | Could |

## Goal

Identify the current Administrator context and provide access to account actions.

## Requirements

| ID | Requirement |
| --- | --- |
| RS-DASH-PRO-01 | The header shall display the current Administrator name or recognizable avatar. |
| RS-DASH-PRO-02 | Selecting the profile control shall open an account menu. |
| RS-DASH-PRO-03 | Authentication-dependent actions may remain disabled until authentication is implemented. |

## Acceptance criteria

- The current Admin context is visible.
- The profile control does not navigate to a broken destination.
