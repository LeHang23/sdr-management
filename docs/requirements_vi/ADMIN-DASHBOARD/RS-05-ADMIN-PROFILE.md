# RS-05 - Hồ sơ Administrator

| Trường | Giá trị |
| --- | --- |
| Màn hình | Admin Dashboard |
| FBS | FBS-1.0.5, Admin profile |
| Ưu tiên | Could |

## Mục tiêu

Nhận diện context Administrator hiện tại và cung cấp quyền truy cập account action.

## Yêu cầu

| ID | Yêu cầu |
| --- | --- |
| RS-DASH-PRO-01 | Header phải hiển thị tên hoặc avatar có thể nhận biết của Administrator hiện tại. |
| RS-DASH-PRO-02 | Chọn profile control phải mở account menu. |
| RS-DASH-PRO-03 | Action phụ thuộc authentication có thể bị disable cho tới khi authentication được triển khai. |

## Tiêu chí chấp nhận

- Context Admin hiện tại được hiển thị.
- Profile control không điều hướng đến trang lỗi.
